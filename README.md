# Site iTaKuTwitch

Version 1 — landing page sombre noir/rouge.

## Fichiers
- `index.html` : structure du site
- `style.css` : design responsive
- `script.js` : menu mobile + animations

## À personnaliser
1. Remplacer le visuel placeholder du héros par le logo/avatar réel d'iTaKu.
2. Ajouter le vrai planning de stream.
3. Remplacer les cartes vidéo par les miniatures YouTube réelles.
4. Ajouter l'e-mail professionnel réel.
5. Si souhaité, intégrer directement le lecteur Twitch et un flux vidéo YouTube.

## Liens publics vérifiés
Le Linktree public associé à @itaku référence Instagram, Threads, YouTube, Twitch et Kick.

## Réseaux
Les réseaux affichés dans le site reprennent les entrées visibles sur le Linktree fourni par l'utilisateur : Twitch, TikTok, YouTube, Twitter, Discord Server et Un p’tit don ?. Les boutons renvoient au Linktree `https://linktr.ee/itakutwitch`.
